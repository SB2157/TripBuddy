# 🌍 TripBuddy – Travel Explorer Website
<img width="1536" height="1024" alt="tripbuddy" src="https://github.com/user-attachments/assets/def41473-9385-4922-9b6e-da70b08f9f47" />

**TripBuddy** is a beautiful and interactive **travel exploration website** built with **HTML, CSS, and JavaScript**.  
It helps users discover destinations, view travel packages, and check real-time weather information — all with a modern and responsive UI.

---

## ✨ Features

- 🔎 **Destination Search** – find any city or place worldwide  
- 🧳 **Travel Packages** – explore curated travel destinations with images  
- ☁️ **Real-time Weather** – get live weather conditions from OpenWeatherMap API  
- 🎬 **Smooth Animations** – cinematic entrance animations for hero and cards  
- 📱 **Responsive Design** – works seamlessly on mobile, tablet, and desktop  

---

## 🛠️ Technologies Used

- **HTML5** – semantic markup  
- **CSS3** – gradients, animations, responsive design  
- **JavaScript (ES6+)** – DOM manipulation, Fetch API, async/await  
- **OpenWeatherMap API** – real-time weather data  
- **Unsplash (static image sources)** – beautiful travel images  

---

## ⚙️ Setup Instructions

### 1. Get API Key

#### OpenWeatherMap API:
1. Go to [OpenWeather](https://openweathermap.org/api)  
2. Sign up for a free account  
3. Copy your API key from the API keys section
